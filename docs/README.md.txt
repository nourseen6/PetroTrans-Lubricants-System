# Petro Trans Lubricants Management System

## Overview

This project aims to transform the current Excel-based workflow used by Petro Trans into a complete web-based management system.

The company is an authorized distributor of ADNOC lubricants.

Currently, all operations are performed manually using multiple Excel files.

The goal is to replace them with one integrated system.

---

## Current User

- Branch Manager (Single User)

The system should be designed to support multiple users and permissions in the future.
